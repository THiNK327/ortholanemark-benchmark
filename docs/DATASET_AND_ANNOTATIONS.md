# OrthoLaneMark dataset and annotation interface

Use the companion `dataset/` package, **OrthoLaneMark: A Pavement Survey Dataset for Lane-Marking Detection**. Its image manifest covers all 1,391 images with stable anonymized image IDs, six section IDs, exact split/exclusion assignment, intensity/range/annotation paths, geometry, and checksums. Each intensity image has a paired range-image export. Both use PNG with decoded pixels, image modes and dimensions preserved; see `RANGE.md` for range details. The private original-to-public ID mapping is retained outside both public candidates. Sequence IDs are assigned from frozen section/order records, not inferred physical positions. They are not evidence of GPS locations, exact acquisition time, or unseen-route independence.

Authoritative compatibility labels and annotation semantics are documented in the dataset's annotation report. Original accepted polynomial coefficients are retained in the native NumPy order (highest power first) in original pixel coordinates, with x a function of y. They are sampled over full image height; the clicked y range is bookkeeping and is not a visibility interval. The new compact records preserve existing coefficients rather than refitting labels. Compatibility rows remain available. Absent sides have explicit absence and null geometry in the public compact layer; legacy readers use their historical absent-side convention.

`manifests/manifest_paper.json` has the historical `splits` dictionary and per-image entries with `project`, `stem`, `image_path`, and `clean_gt_path`. Paths are relative to the dataset package root. `tools/prepare_manifest.py` validates and resolves these paths for unchanged historical readers. `project`/`stem` now mean public `section_id`/`image_id`; saved prediction arrays and score records use exactly the same IDs and original ordering.

`artifacts/learning/<run_id>/raw_val.npz` and `raw_test.npz` contain `stems`, `projects`, full-height `xL`/`xR`, continuous `cL`/`cR`, native decisions, and dimensions. `predictions_test.npz` contains final thresholded `existsL`/`existsR`. Load these new packaged NPZ files with `numpy.load(..., allow_pickle=False)`. Every array is numeric, boolean, or Unicode; no object array is required. The legacy `evaluation/predictions_io.py` remains unchanged and describes an older object-array format; that format is not the schema of these packaged NPZ files.

A full-height accepted curve does not establish visible paint at every row. Original clicks and annotation history are retained only when recorded. Consensus adjudication involved the two annotators and a third reviewer; no vote history or independent third annotation is invented. The two-pixel reviewer-agreement tolerance was not used as a migration tolerance or as a calibrated absolute uncertainty.
