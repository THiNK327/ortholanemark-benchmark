# OrthoLaneMark license status

The proposed release terms are MIT for benchmark-authored code, CC BY 4.0 for the dataset, and CC BY 4.0 for the selected checkpoints. These are preparation choices for the all-author release review; they are not a license grant and are not mandated by ASCE.

Existing third-party components retain their own upstream licenses and notices. Exact Kornia, Idelbayev ResNet, LaneATT NMS, torchvision and MMDetection notices are now included in `LICENSES/` with source hashes and a component mapping. Modified-file and component attribution prefixes are verified to contain comments only. A top-level code license will apply only to the material its rights holder can license, without replacing retained upstream terms.

The copyright holder for the new code/data/checkpoints has not been inferred from paper authorship or journal copyright arrangements. Record the appropriate holder and distribution authority during the coauthor review. Public publication remains pending agreement of all authors, as requested on September 27, 2026.

See [the release plan](docs/RELEASE_PLAN.md) for sources, timing and the two planned Zenodo records. Actual license fields remain unset until the final release decision; proposed terms are stored separately in `RELEASE_METADATA.json`. `LICENSE.proposed` provides a concrete MIT draft for the benchmark-authored portion. The checkpoint proposal is not a verified blanket CC BY 4.0 grant: see `docs/CHECKPOINT_RIGHTS.md`.
